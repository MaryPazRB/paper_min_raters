Distribution of real (reference) disease severity for the nine pathosystems included in the SAD validation analysis. Histograms use the actual severity values in all_data.xlsx, with common 5-percentage-point bins and identical axes across panels. Repeated observations from different raters are counted once per image and reference set. Panel E includes both independently measured reference sets for the same 30 Gerbera images (60 reference measurements in total); these values are retained separately rather than averaged. Panel labels report the number of images. Reference severities are those recorded in the compiled workbook.
